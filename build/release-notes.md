A living notch for Windows 10 (1903 or later) and Windows 11.

## Download

- **`Jer.exe`**: the whole app in one file (under 1 MB). Download it and run it. No installer and nothing else to install.
- `Jer.zip`: the same `Jer.exe` in a zip, if your browser blocks .exe downloads.

Windows SmartScreen may warn because Jer is new and not signed: choose **More info → Run anyway**. `SHA256SUMS.txt` lists the SHA-256 of both files so you can check your download.

**Updating:** just run the new `Jer.exe`. If an older Jer is running, the new one closes it and takes its place. Your tasks, water log, shelf and settings stay.

**Bahasa Indonesia:** unduh `Jer.exe`, lalu jalankan. Tidak perlu install apa pun. Kalau Jer versi lama masih berjalan, Jer yang baru otomatis menutupnya dan menggantikannya; data dan pengaturan kamu tetap ada. Kalau muncul peringatan SmartScreen, pilih **More info → Run anyway**.

## What's new in 2.0

- **About 1 MB instead of 70 MB.** Jer now runs on the .NET Framework that is already part of Windows, so the download no longer carries its own runtime. It also starts faster and uses less memory.
- **One exe for every PC**, including Windows on ARM.
- **Lyrics keep up with your music.** Skipping songs never shows the previous song's lyrics, a lookup made before Spotify reports the song length is redone, songs whose length differs a little from LRCLIB still match, and a missed lookup is retried instead of being remembered.
- **Updates replace the running copy.** Starting a new Jer.exe closes the old version, and Jer shows which version is now running.
- The Pomodoro countdown ticks once per second without skipping numbers.

Settings: click the Jer icon next to the clock. Move the notch to another display in **Settings → Display** or from the tray menu under **Show notch on**.
